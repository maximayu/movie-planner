## Ver.0.4：ハシゴ可能判定

### マイルストーン
2作品を続けて観られる組み合わせを判定できる。

### 仕様
以下の条件で鑑賞可能か判定する。

- 同じ映画館の場合：上映間隔10分以上
- 違う映画館の場合：上映間隔30分以上
- 2作品の順番は問わない
- どちらの上映回も指定した空き時間内に収まる
- 前の映画の終了時刻より後に次の映画が始まる

判定式：

次の上映開始時刻  
≧ 前の上映終了時刻  
＋ 必要な移動・余裕時間

### 完了条件
- [ ] 同じ映画館の組み合わせを判定できる
- [ ] 違う映画館の組み合わせを判定できる
- [ ] 上映時間が重なる組み合わせを除外できる
- [ ] 空き時間外の上映回を除外できる
- [ ] 作品の順番を入れ替えて判定できる

並び順：

1. 合計料金が安い
2. 待ち時間が短い

### 完了条件

- [ ] 複数の候補をランキング表示できる
